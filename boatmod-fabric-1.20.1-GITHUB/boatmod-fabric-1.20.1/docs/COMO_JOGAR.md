# Como jogar com o BoatMod

## Passo a passo com imagens

### 1. Barco normal (1 remo) - Imagem 2 do pedido
Coloque um barco vanilla. Ele tem 1 remo e anda 8 blocos/s.

### 2. Adicionando remos - Imagem 3
Segure **Remo** (`boatmod:oar`) e clique direito no barco:
- Cada clique = +1 remo
- Máximo 12 remos
- 8 remos (4 cada lado) = super veloz, igual sua Imagem 3!

> Dica: use `Graveto` ou `Pá de Madeira` para testar sem craftar o remo.

### 3. Turbo de Baiacu - Imagem 1 (jato branco)
Segure **Baiacu** e clique direito no barco:
- Até 4 baiacus
- Entre no barco e aperte **G**
- Efeito: partículas `cloud` brancas gigantes atrás + som de foguete!

## Atalhos

- `G` = Turbo (configurável em Opções → Controles → BoatMod)
- `Shift + Mão vazia` em barco = remove 1 remo

## Comandos úteis

```
/give @p boatmod:oar 64
/give @p minecraft:pufferfish 64
```

## Troubleshooting

**Não consigo adicionar remo?**
- Verifique se está segurando remo/graveto e NÃO está com Shift
- Verifique se não atingiu 12 remos

**Turbo não funciona?**
- Precisa ter pelo menos 1 baiacu no barco
- Precisa estar DENTRO do barco
- Verifique se a tecla G não conflita com outro mod
