# Contribuindo com o BoatMod

Obrigado por querer contribuir! 💙

## Como contribuir

1. **Fork** o repositório
2. Crie uma branch: `git checkout -b feat/minha-feature`
3. Faça suas alterações
4. Teste: `./gradlew build` e teste no jogo
5. Commit: `git commit -m "feat: minha feature incrível"`
6. Push: `git push origin feat/minha-feature`
7. Abra um **Pull Request**

## Padrões

- Código em inglês, comentários em pt-BR ok
- Use Java 17 features quando fizer sentido
- Teste com 1, 8 e 12 remos antes de PR
- Siga o estilo: 4 espaços, sem tabs
