## [1.0.0] - 2026-10-21
### Added
- Barco com até 12 remos (cada um +15% velocidade)
- Clique direito com Remo/Graveto para adicionar remo
- Clique direito com Baiacu para instalar propulsor (até 4)
- Tecla G para turbo com partículas de vento (cloud)
- Receita de Remo, suporte a 1.20.1 Fabric
- Mixin no tick do barco para bônus de velocidade
